# Rock, Paper, Scissors

A simple, browser-based Rock, Paper, Scissors game. Play against the computer in a first-to-three match.

## How to play

1. Open `index.html` in a web browser.
2. Read the instructions and click **OK**.
3. Enter `rock`, `paper`, or `scissors` when prompted. Choices are case-insensitive, and extra spaces are ignored.
4. Review each round's result and scoreboard in the alert.

The first player to score 3 points wins. Draws do not award points. Press **Cancel** at a choice prompt to end the game and see the final score.

## Rules

- Rock beats scissors.
- Paper beats rock.
- Scissors beats paper.
- Matching choices are a draw.

## Round details

Round results are also written to the browser's developer console. To open it:

- **Windows/Linux, Chrome:** press `F12` or `Ctrl+Shift+J`.
- **macOS, Chrome:** press `Cmd+Option+J`.

## Project files

- `index.html` — page entry point; loads the game script.
- `script.js` — game logic, prompts, alerts, and console output.

No installation or build step is required.
